# Li Si'ao — Prototype

Prototype UI untuk platform koleksi lagu rohani berbahasa Nias.

## Menjalankan proyek

Pastikan Node.js versi 20.9 atau lebih baru sudah terpasang.

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Isi prototype

- Tampilan beranda responsif untuk desktop, tablet, dan mobile
- Navigasi sidebar dan menu mobile
- Pencarian dan filter contoh lagu
- Modal detail dan lirik contoh
- Player bar interaktif (simulasi, belum memutar file audio)
- Tombol simpan ke playlist sementara
- Tombol area admin simulasi

## Catatan penting

Semua judul, lirik, jumlah lagu, dan durasi pada versi ini adalah data demonstrasi. Belum ada lagu/audio asli, login sungguhan, database, atau upload file. Gunakan hanya materi lagu, terjemahan, rekaman, dan aset visual yang hak penggunaannya sudah dipastikan.

## Teknologi

Next.js, React, TypeScript, Tailwind CSS, Lucide React, Framer Motion (dependency disiapkan untuk pengembangan animasi berikutnya).
